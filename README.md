## 🚀 Featured Projects

### 💳 NexPay – Distributed Payment Gateway

**A microservices-based payment gateway exploring distributed systems and backend engineering concepts.**

Building NexPay has given me hands-on experience designing and implementing backend components beyond basic CRUD APIs.

- Developed payment processing workflows supporting Card, UPI, Net Banking, and Wallet transactions using the Strategy Pattern.
- Implemented a secure card vault using AES-256 envelope encryption and PCI-DSS-aligned security controls.
- Applied Saga Pattern and Transactional Outbox for reliable distributed transaction processing across PostgreSQL and Kafka.
- Implemented Redis SETNX-based idempotency, Resilience4j circuit breakers, and asynchronous messaging.
- Built webhook delivery with HMAC-SHA256 signatures, exponential backoff, up to 7 retries, and Dead Letter Queue replay.
- Deployed microservices on Kubernetes with Horizontal Pod Autoscaling and integrated Prometheus, Grafana, and Zipkin.
- Conducted API-level performance testing using Apache JMeter.

**Tech Stack:** Java · Spring Boot · PostgreSQL · Redis · Kafka · Docker · Kubernetes · Prometheus · Grafana · Zipkin
